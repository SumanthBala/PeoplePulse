# PeoplePulse Admin UI Updates

Implemented without changing the existing H2 `data` database or recruitment workflow.

## Changes
- Removed the blank analytics/chart screens from the UI.
- Removed the old Salary by Project pie chart.
- Admin dashboard now keeps the useful summary cards and a clean overview panel.
- Profile is no longer a separate sidebar page. Click the signed-in user card at the bottom of the sidebar to open a profile popup.
- User photo is shown on the left side of the username card.
- Profile popup supports Add/Change Photo and Remove Photo, plus existing profile fields.
- Selected Employees and Rejected Employees now have search.
- Selected/Rejected candidate cards include a downloadable recruitment process report (HTML report).
- Projects & Jobs now has a search box for project name, job role, location, skills and experience.
- Added lighter pastel UI styling while preserving existing functionality.

No existing employee/project/application data is deleted.
